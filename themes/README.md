# Bundled themes

- `osier-catppuccin.json`: Catppuccin Mocha and Latte, generated by the `osier-theme` crate
  from the official palette (MIT). Do not edit by hand; change `crates/osier-theme/src` and run
  `cargo test -p osier-theme -- --ignored write_bundled_catppuccin`. A test fails when the file
  is stale.
- `catppuccin.json`: copied from [gpui-kit](https://github.com/longbridge/gpui-kit)
  (Apache-2.0) for the Frappe and Macchiato flavours.
- `template.json`: a starting point for user themes, see `docs/themes.md`.

Files in this folder are embedded into the binary. User themes go in `~/.config/osier/themes/`.
