# Bundled themes

`catppuccin.json` is copied from [gpui-kit](https://github.com/longbridge/gpui-kit) (Apache-2.0),
palette by [Catppuccin](https://github.com/catppuccin/catppuccin) (MIT). It is a placeholder until
Osier ships its own tuned Catppuccin Mocha and Latte files.

Files in this folder are embedded into the binary. User themes go in `~/.config/osier/themes/`.
